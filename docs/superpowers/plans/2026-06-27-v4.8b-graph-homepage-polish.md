# V4.8b Graph Homepage Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish the graph-first homepage with an accessible six-result combobox, shareable URL focus, reset control, complete color legend, and mobile-safe layout.

**Architecture:** Keep the existing philosophy graph view model and Cytoscape local-graph renderer. Add a pure search-ranking helper for unit testing, then extend the existing React island with combobox state and URL synchronization; CSS remains scoped to the graph homepage.

**Tech Stack:** Astro 6.4, React 19 island, Cytoscape 3, TypeScript, Node test runner, Playwright.

## Global Constraints

- Do not modify `src/content.philosophy.ts` or any content schema.
- Do not add package dependencies.
- Do not add a global graph, AI clustering, graph editor, node weights, or ability profile.
- Node selection changes the graph center and URL only; it never navigates to a detail page.
- Search results are limited to six and expose mouse plus ArrowUp/ArrowDown/Enter/Escape operation.
- URL focus uses `history.replaceState`; Reset returns to `graph.defaultCenterId` and removes `focus`.
