codeExamples:
  - title: naive
    description: 把变量名当成独立副本时，共享可变对象会产生意外结果。
    code: |
      tasks = []
      today = tasks

      tasks.append("send report")

      print(today)
  - title: standard
    description: 需要保留当时状态时，显式创建一个新对象，而不是只换一个名字。
    code: |
      tasks = []
      today = list(tasks)

      tasks.append("send report")

      print(today)
      print(tasks)
  - title: production
    description: 工程代码会把“快照”边界写成函数，并用不可变返回值减少误改。
    code: |
      from typing import Iterable

      def snapshot_tasks(tasks: Iterable[str]) -> tuple[str, ...]:
          return tuple(tasks)

      tasks = ["send report"]
      today = snapshot_tasks(tasks)
      tasks.append("archive files")

      print(today)
      print(tasks)

变量最容易被误解成“装值的盒子”。在 Python 里，更准确的理解是“名字绑定对象”。这会影响你理解列表、函数参数、可变对象和闭包。
