title: break、continue 与 pass
summary: break、continue 和 pass 用来精确控制循环与代码块的执行节奏。
whyImportant: 写遍历、搜索或输入校验时，循环不总是完整跑完。掌握这三个关键字，才能清晰表达“找到就停”“跳过异常项”“先保留结构”等真实意图。
definition: break 结束最近一层循环，continue 跳到下一轮循环，pass 什么也不做但保留语法位置。
mentalModel: break 是停止按钮，continue 是跳过按钮，pass 是先留一个空座位。

codeExamples:
  - title: naive
    description: 没有 break 和 continue 时，空值和终止标记也会被当成正常数据处理。
    code: |
      raw_names = [" Ada ", "", "Guido", "STOP", "Grace"]
      names = []

      for raw in raw_names:
          names.append(raw.strip().title())

      print(names)
  - title: standard
    description: break 表达“到此为止”，continue 表达“这一项跳过”。
    code: |
      raw_names = [" Ada ", "", "Guido", "STOP", "Grace"]
      names = []

      for raw in raw_names:
          text = raw.strip()
          if text == "STOP":
              break
          if not text:
              continue
          names.append(text.title())

      print(names)
  - title: production
    description: 工程版把循环控制写进函数，并把未来要处理的分支用 pass 明确留位。
    code: |
      from typing import Iterable

      def collect_names(raw_names: Iterable[str]) -> list[str]:
          names: list[str] = []

          for raw in raw_names:
              text = raw.strip()
              if text == "STOP":
                  break
              if not text:
                  continue
              if text.startswith("#"):
                  pass
              else:
                  names.append(text.title())

          return names

      print(collect_names([" Ada ", "", "# metadata", "Guido", "STOP", "Grace"]))
---
这三个关键字都很小，但能显著改变阅读顺序。用它们时要让读者很快看懂“为什么停下”或“为什么跳过”。
