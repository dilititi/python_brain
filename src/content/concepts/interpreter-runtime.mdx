## 概念定义

解释型执行不等于“没有编译”，而是说学习者主要感受到的是运行时反馈：敲一段、跑一段、立刻看到错误。Python 会把源码编译成字节码，再由虚拟机执行，但新手最先需要掌握的是“哪个解释器在执行、它的版本是多少、它从哪里找模块”。

这也是为什么环境问题在 Python 学习中很早出现。编辑器、终端、虚拟环境、系统 Python 可能指向不同解释器；同一段代码在不同解释器上，看到的包、版本和语法支持都可能不同。

## 代码示例

最小动作是打印 `sys.version` 和 `sys.executable`。当你能说清楚“当前代码由哪个 python.exe / python 命令执行”，后面排查 pip 安装、模块导入和版本差异会容易很多。

## 历史脉络

Python 从一开始就提供脚本执行和交互式体验。这个反馈速度让它适合教学、自动化和数据探索，也让“环境身份检查”成为 Foundation 层必须掌握的第一类技能。
