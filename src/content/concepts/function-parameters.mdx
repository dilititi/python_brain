## 概念定义

函数参数是 API 设计的入口。参数越清楚，调用者越不容易猜错；默认值和可变参数越随意，后期维护越容易混乱。

位置参数适合短而自然的输入，关键字参数适合强调含义，默认值适合表达常见情况，`*args` 和 `**kwargs` 适合扩展点。它们不是越多越好，而是要服务调用者的理解。

## 历史脉络

Python 的函数参数模型从早期就支持默认值和关键字调用，后来又逐步补充仅位置参数、仅关键字参数和类型注解等表达方式。它的演进方向很稳定：让函数调用既灵活，又能在签名里暴露足够多的意图。
