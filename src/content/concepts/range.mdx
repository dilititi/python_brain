---
title: range
summary: range 表示按规则生成的整数序列，常用于循环计数。
whyImportant: 新手常把 range 当列表，但它实际按需产生数字。理解这一点能写出更省内存的循环，也能读懂索引遍历和批量生成场景。
definition: range 是不可变的整数序列类型，按需生成数字而不是一次性保存所有数字。
mentalModel: range 像一个数字规则，不是一袋已经装好的数字。

codeExamples:
  - title: naive
    description: 忘记 range 的 stop 不包含终点时，最后一项会被漏掉。
    code: |
      total_pages = 3
      pages = []

      for page in range(1, total_pages):
          pages.append(page)

      print(pages)
  - title: standard
    description: range 的右边界是开区间，需要把包含的终点加一。
    code: |
      total_pages = 3
      pages = list(range(1, total_pages + 1))

      print(pages)
  - title: production
    description: 工程版保留 range 的惰性序列特性，并在入口检查边界。
    code: |
      def page_numbers(total_pages: int) -> range:
          if total_pages < 1:
              raise ValueError("total_pages must be positive")
          return range(1, total_pages + 1)

      print(list(page_numbers(3)))
---
`range(10)` 不是“列表 0 到 9”，而是一个可迭代的范围对象。这个区别在大范围数据时很重要。
