codeExamples:
  - title: naive
    description: 把 for 循环当索引机器用，容易写出越界问题。
    code: |
      tasks = ["read", "clean", "save"]

      for index in range(len(tasks) + 1):
          try:
              print(tasks[index])
          except IndexError as error:
              print(type(error).__name__)
  - title: standard
    description: Python 的 for 循环通常直接遍历对象，需要位置时再用 enumerate。
    code: |
      tasks = ["read", "clean", "save"]

      for position, task in enumerate(tasks, start=1):
          print(f"{position}. {task}")
  - title: production
    description: 工程版把遍历逻辑封装成函数，并处理空白任务这类边界。
    code: |
      from typing import Iterable

      def format_tasks(tasks: Iterable[str]) -> list[str]:
          lines: list[str] = []

          for position, task in enumerate(tasks, start=1):
              cleaned = task.strip()
              if not cleaned:
                  continue
              lines.append(f"{position}. {cleaned}")

          return lines

      print(format_tasks(["read", " ", "save"]))

`for i in range(10)` 只是入口。真正的 Pythonic 写法通常是“直接遍历对象”，比如 `for row in rows` 或 `for filename in path.iterdir()`。
