## 概念定义

`import` 不是全网搜索，也不是搜索整个磁盘。它会按规则查看 `sys.path` 里的目录。这个列表通常包含当前脚本所在目录、标准库路径、虚拟环境的 `site-packages`，以及环境变量配置的额外路径。

导入问题最常见的三连问是：当前解释器是谁？当前运行目录在哪里？`sys.path` 里有没有目标模块所在目录？

## 历史脉络

模块查找路径看似工程细节，却是 Python 项目化的关键。它把解释器、包结构、虚拟环境和第三方依赖连接成一条可以排查的链。
