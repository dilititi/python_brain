definition: if 语句会计算一个布尔条件，并只执行满足条件的代码块。
mentalModel: if 像路口的分岔牌，条件成立走一条路，不成立走另一条路。

codeExamples:
  - title: naive
    description: 多分支顺序写错时，较宽的条件会提前吃掉更精确的情况。
    code: |
      score = 92

      if score >= 60:
          level = "pass"
      elif score >= 90:
          level = "excellent"
      else:
          level = "retry"

      print(level)
  - title: standard
    description: if/elif/else 应该先处理更具体的分支，再处理兜底分支。
    code: |
      score = 92

      if score >= 90:
          level = "excellent"
      elif score >= 60:
          level = "pass"
      else:
          level = "retry"

      print(level)
  - title: production
    description: 工程版把分支规则封装成函数，并先校验输入范围。
    code: |
      def grade(score: int) -> str:
          if score < 0 or score > 100:
              raise ValueError("score must be between 0 and 100")
          if score >= 90:
              return "excellent"
          if score >= 60:
              return "pass"
          return "retry"

      for score in [92, 75, 40]:
          print(score, grade(score))

`if` 的重点不是“判断大小”，而是把业务规则翻译成明确的分支。输入校验、权限判断、异常兜底和数据清洗都会反复用到它。
