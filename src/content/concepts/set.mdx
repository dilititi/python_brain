title: 集合
summary: 集合保存不重复元素，适合去重、成员测试和集合运算。
whyImportant: 名单比对、去重、标签过滤和权限判断常常只关心“在不在”。set 的成员查询和交并差运算能让这些代码更直接。
definition: set 是可变集合类型，frozenset 是不可变集合类型。
mentalModel: 集合像一张成员名单，只关心某个元素在不在，不关心位置。

codeExamples:
  - title: naive
    description: 用列表做名单比对时，重复项和手写判断会让结果变得噪声很大。
    code: |
      completed = ["python", "data", "python"]
      required = ["python", "git"]
      missing = []

      for topic in required:
          if topic not in completed:
              missing.append(topic)

      print(completed)
      print(missing)
  - title: standard
    description: set 直接表达去重、成员测试和差集。
    code: |
      completed = {"python", "data", "python"}
      required = {"python", "git"}

      print(completed)
      print(required - completed)
  - title: production
    description: 工程版规范化输入，并用 frozenset 表达不可变的必修集合。
    code: |
      from typing import Iterable

      REQUIRED_TOPICS = frozenset({"python", "git"})

      def missing_topics(completed: Iterable[str]) -> set[str]:
          normalized = {topic.strip().lower() for topic in completed if topic.strip()}
          return set(REQUIRED_TOPICS - normalized)

      print(missing_topics([" Python ", "data", "python"]))
---
集合适合回答“有没有”“重复不重复”“两组数据差在哪”。它不是列表的替代品，而是另一种问题模型。
