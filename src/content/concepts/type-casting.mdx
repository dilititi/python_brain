mentalModel: 类型转换像把同一份信息换一种容器或表示法，但转换可能失败或丢失信息。

codeExamples:
  - title: naive
    description: 把数字文本当成数字使用，会得到字符串拼接而不是数值计算。
    code: |

      print(raw_count + "2")
  - title: standard
    description: 用 int 显式转换后，数据才进入可计算形状。
    code: |
      raw_count = "8"
      count = int(raw_count)

      print(count + 2)
  - title: production
    description: 真实输入要处理空格、非法值和业务边界。
    code: |
      def parse_quantity(raw: str) -> int:
          try:
              quantity = int(raw.strip())
          except ValueError as error:
              raise ValueError("quantity must be an integer") from error

          if quantity < 0:
              raise ValueError("quantity cannot be negative")

          return quantity

      for raw in ["8", " 2 "]:
          print(parse_quantity(raw) + 2)
