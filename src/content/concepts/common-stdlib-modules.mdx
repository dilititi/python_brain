## 概念定义

标准库不是“顺便知道一下”的附录。对新人来说，它是从语法走向实际任务的桥：读取系统信息、处理日期、解析 JSON、匹配文本、操作路径，都可以先从标准库开始。

这个节点不替代 `json`、`re`、`pathlib` 的深页，而是给学习者建立入口地图：遇到某类问题时，知道应该先去哪个模块看。

## 真实案例

`stdlib-import-tour` 案例把 `os`、`sys`、`math`、`datetime`、`re` 放在同一个小脚本里。它的目标不是背 API，而是让新人形成“先找标准库”的习惯。

## 历史脉络

Python 社区常说 batteries included，意思是语言自带足够多的实用工具。这个传统也是 Python 能快速用于自动化、后端脚本和数据预处理的重要原因。
