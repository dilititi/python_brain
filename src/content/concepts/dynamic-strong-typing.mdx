## 概念定义

“动态类型”说的是名字不需要预先声明类型，不是对象没有类型。`score = 10` 之后，`score` 这个名字绑定到了一个 `int` 对象；下一行再写 `score = "10"`，名字换了绑定对象，但两个对象各自的类型并没有消失。

“强类型”说的是类型规则会被认真执行。`"3" + 4` 不会自动猜成 `7`，因为字符串拼接和数字加法是两套不同操作。你要写出 `int("3") + 4`，让转换变成显式动作。

## 真实案例

Web 表单、命令行参数和环境变量通常先以字符串进入程序。数据分析里的 CSV 字段也常常先是文本。能不能把文本转换成数字、日期或布尔值，是输入校验和错误处理的核心。

## 历史脉络

Python 一直是动态强类型语言。后来类型注解进入语言生态，是为了让编辑器、mypy、pyright 等工具更早发现问题，而不是把 Python 改造成静态语言。
