## 概念定义

这不是一个语法节点，而是新人进入 Python 世界的总入口。解释型决定了反馈方式，动态类型决定了写代码的节奏，强类型决定了不同类型不会随意混算，多范式决定了你可以按任务选择过程式、函数式或面向对象写法。

“跨平台”和“开源社区驱动”也不是背景信息。它们解释了为什么同一份 Python 代码能在 Windows、macOS、Linux 上运行，也解释了为什么标准库、PyPI、PEP 和 PSF 会成为学习 Python 的基础设施。

## 代码示例

语言身份的代码示例不追求算法复杂度，而是建立环境观察能力：版本、平台、解释器路径、最低版本检查。这个能力会直接帮助新人排查“为什么我这里能跑，你那里不能跑”的问题。

## 历史脉络

Python 从 1991 年公开发布开始，就围绕可读性、可移植性和可扩展标准库成长。后续 Python 2 到 Python 3 的分叉与迁移，也说明了“语言身份”会真实影响项目选型、依赖版本和学习材料选择。
