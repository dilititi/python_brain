---
title: 类型注解
summary: 类型注解标出变量、参数和返回值的预期类型，供人和工具读取。
whyImportant: 项目变大后，只靠变量名很难看出数据形状。注解能改善补全、重构和静态检查，也让函数契约更清楚。
definition: 类型注解是 Python 的可选类型标记，不改变运行时动态类型本质，但能被工具读取。
mentalModel: 类型注解像代码旁边的路标，告诉读者和工具这里期待什么形状的数据。

codeExamples:
  - title: naive
    description: 没有注解时，调用者可能传入看似能用、实际语义错误的数据。
    code: |
      def minutes_to_seconds(minutes):
          return minutes * 60

      print(minutes_to_seconds("5"))
  - title: standard
    description: 注解把参数和返回值的预期类型写进函数签名。
    code: |
      def minutes_to_seconds(minutes: int) -> int:
          return minutes * 60

      print(minutes_to_seconds(5))
  - title: production
    description: 工程版在注解之外补上边界检查，因为注解本身不负责运行时校验。
    code: |
      def minutes_to_seconds(minutes: int) -> int:
          if minutes < 0:
              raise ValueError("minutes cannot be negative")
          return minutes * 60

      durations = [5, 0, 90]

      for duration in durations:
          print(minutes_to_seconds(duration))
---
类型注解不是把 Python 变成静态语言。它保留运行时灵活性，同时给编辑器、mypy、pyright 和团队协作更多上下文。
