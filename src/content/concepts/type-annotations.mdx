title: 类型注解
summary: 类型注解标出变量、参数和返回值的预期类型，供人和工具读取。
whyImportant: 项目变大后，只靠变量名很难看出数据形状。注解能改善补全、重构和静态检查，也让函数契约更清楚。
definition: 类型注解是 Python 的可选类型标记，不改变运行时动态类型本质，但能被工具读取。
mentalModel: 类型注解像代码旁边的路标，告诉读者和工具这里期待什么形状的数据。

codeExamples:

    code: |

          if age is None:
              return f"Hello, {name}"
          return f"Hello, {name}, age {age}"

      print(greet("Ada"))

类型注解不是把 Python 变成静态语言。它保留运行时灵活性，同时给编辑器、mypy、pyright 和团队协作更多上下文。
