codeExamples:
  - title: naive
    description: 用字典和散落函数表达同一个实体时，字段名和规则容易漂移。
    code: |
      account = {"owner": "Ada", "balance": 100}

      def deposit(account_data, amount):
          account_data["money"] = account_data.get("money", 0) + amount

      deposit(account, 50)
      print(account)
  - title: standard
    description: class 把数据和围绕这些数据的行为放进同一个对象。
    code: |
      class BankAccount:
          def __init__(self, owner, balance=0):
              self.owner = owner
              self.balance = balance

          def deposit(self, amount):
              self.balance += amount

      account = BankAccount("Ada", 100)
      account.deposit(50)
      print(account.owner, account.balance)
  - title: production
    description: 工程版把对象不变量写进方法边界，避免外部随意破坏状态。
    code: |
      class BankAccount:
          def __init__(self, owner: str, balance: int = 0):
              if balance < 0:
                  raise ValueError("balance cannot be negative")
              self.owner = owner
              self._balance = balance

          @property
          def balance(self) -> int:
              return self._balance

          def deposit(self, amount: int) -> None:
              if amount <= 0:
                  raise ValueError("amount must be positive")
              self._balance += amount

      account = BankAccount("Ada", 100)
      account.deposit(50)
      print(account.balance)

类不是每个脚本都必须用。它适合在“同一组数据和行为总是一起出现”时，把散落的函数和字典收束成一个类型。
