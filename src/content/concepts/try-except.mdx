title: try-except
summary: try-except 捕获运行时异常，让失败操作进入可控恢复路径。
whyImportant: 文件不存在、网络失败、解析错误都不能靠 if 全部预判。异常处理让程序能区分预期失败和真正崩溃，写出稳定脚本。
definition: try-except 是 Python 的异常处理结构，用来处理运行时错误。
mentalModel: try 像把危险动作放进保护区；如果出错，就跳到对应的 except 处理。

codeExamples:
  - title: naive
    description: 裸 except 会把所有失败都吞掉，调用者看不出哪些输入坏了。
    code: |
      raw_ids = ["42", "bad", "0"]

      for raw in raw_ids:
          try:
              print(int(raw))
          except:
              print(0)
  - title: standard
    description: 只捕获预期异常，并让恢复策略保持可见。
    code: |
      raw_ids = ["42", "bad", "0"]

      for raw in raw_ids:
          try:
              value = int(raw)
          except ValueError:
              print(f"skip invalid id: {raw}")
              continue

          print(value)
  - title: production
    description: 工程版把异常处理、业务边界和可观察日志放进同一个解析函数。
    code: |
      def parse_positive_ids(raw_ids: list[str]) -> list[int]:
          ids: list[int] = []

          for raw in raw_ids:
              try:
                  value = int(raw)
              except ValueError:
                  print(f"skip invalid id: {raw}")
                  continue

              if value <= 0:
                  print(f"skip non-positive id: {value}")
                  continue

              ids.append(value)

          return ids

      print(parse_positive_ids(["42", "bad", "0", "7"]))
---
异常处理不是把错误吞掉。好的 `except` 应该尽量具体，并且让调用者知道程序采取了什么恢复策略。
