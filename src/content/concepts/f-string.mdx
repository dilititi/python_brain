---
title: f-string
summary: f-string 把表达式直接嵌入字符串，是现代 Python 推荐的格式化写法。
whyImportant: 日志、报表、错误信息和命令行输出都需要拼文本。f-string 让变量和表达式留在原位，减少拼接噪音，也方便控制数字和日期格式。
definition: f-string 是以 f 或 F 开头的格式化字符串字面量，可以在花括号里放表达式。
mentalModel: f-string 像一张带占位槽的模板，运行时把槽里的表达式算出来再填进去。

codeExamples:
  - title: naive
    description: 手动拼接文本时，数字和字符串混在一起很容易出错。
    code: |
      name = "Ada"
      file_count = 3

      try:
          message = "User " + name + " has " + file_count + " files"
      except TypeError as error:
          print(type(error).__name__)
  - title: standard
    description: f-string 让变量和表达式直接留在模板里，避免手动转换噪音。
    code: |
      name = "Ada"
      file_count = 3

      message = f"User {name} has {file_count} files"
      print(message)
  - title: production
    description: 真实输出通常还要处理格式、边界条件和函数签名。
    code: |
      from datetime import date

      def format_report(owner: str, file_count: int, generated_on: date) -> str:
          if file_count < 0:
              raise ValueError("file_count cannot be negative")
          return f"{owner} has {file_count:,} files on {generated_on:%Y-%m-%d}"

      print(format_report("Ada", 1200, date(2026, 6, 1)))
---
f-string 的价值是让“文本模板”和“变量来源”贴在一起。它比字符串拼接更可读，也比许多旧式格式化写法更直接。
