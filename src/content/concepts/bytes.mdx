title: bytes 与 bytearray
summary: bytes 和 bytearray 用字节序列表示文件、网络和编码后的二进制数据。
whyImportant: 处理图片、接口响应、压缩包或编码转换时，数据常常不是 str。理解字节类型能避免乱码、解码失败和二进制文件被当文本处理的问题。
definition: bytes 是不可变的字节序列，bytearray 是可变的字节序列。
mentalModel: str 面向人类文本，bytes 面向机器数据。编码就是两者之间的桥。

codeExamples:
  - title: naive
    description: 把 str 当成 bytes 拼接时，文本和二进制边界会立刻暴露。
    code: |
      header = b"USER:"
      name = "Ada"

      try:
          packet = header + name
      except TypeError as error:
          print(type(error).__name__)
  - title: standard
    description: str 和 bytes 之间必须显式 encode / decode。
    code: |
      header = b"USER:"
      name = "Ada"

      packet = header + name.encode("utf-8")
      print(packet)
      print(packet.removeprefix(header).decode("utf-8"))
  - title: production
    description: 工程版检查字节头和长度，再把 bytearray 的可变处理转回不可变 bytes。
    code: |
      def decode_user_packet(packet: bytes) -> str:
          prefix = b"USER:"
          if not packet.startswith(prefix):
              raise ValueError("packet must start with USER:")

          payload = bytearray(packet.removeprefix(prefix))
          if not payload:
              raise ValueError("packet payload is empty")

          return bytes(payload).decode("utf-8")

      print(decode_user_packet(b"USER:Ada"))

只要处理文件上传、图片、压缩包、网络响应或编码问题，bytes 就会出现。新人阶段先记住：文本和字节不是同一种东西。
