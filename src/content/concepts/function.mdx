title: 函数
summary: 函数把一段逻辑命名、参数化，并作为可复用的调用单元。
whyImportant: 函数让脚本从一长串步骤变成可组合的小块。它是测试、复用、装饰器、回调和框架接口的共同基础，也是项目开始变复杂时的第一道结构线。
definition: 函数是一段可调用对象，它接收输入，执行逻辑，并可返回结果。
mentalModel: 函数像一台小机器，把输入放进去，得到输出；机器本身也可以作为值传递。

codeExamples:
  - title: naive
    description: 没有函数时，同一段求和逻辑会在脚本里反复复制。
    code: |
      morning_scores = [3, 5, 8]
      morning_total = 0
      for score in morning_scores:
          morning_total += score

      evening_scores = [2, 4]
      evening_total = 0
      for score in evening_scores:
          evening_total += score

      print(morning_total, evening_total)
  - title: standard
    description: 函数把过程包装成可以命名、复用和测试的单元。
    code: |
      def total(scores):
          result = 0
          for score in scores:
              result += score
          return result

      print(total([3, 5, 8]))
      print(total([2, 4]))
  - title: production
    description: 工程版用类型注解和边界检查明确函数契约。
    code: |
      from typing import Iterable

      def total_scores(scores: Iterable[int]) -> int:
          result = 0

          for score in scores:
              if score < 0:
                  raise ValueError("score cannot be negative")
              result += score

          return result

      print(total_scores([3, 5, 8]))
