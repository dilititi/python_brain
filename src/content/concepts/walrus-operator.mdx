    description: walrus 把表达式结果绑定到名字，再在同一块逻辑里复用。
    code: |

    description: 工程版把重复模式封装成函数，并明确处理空行边界。
    code: |
      def normalized_nonempty(lines: list[str]) -> list[str]:
          result: list[str] = []

          for line in lines:
              if clean := line.strip():
                  result.append(clean.lower())

          return result

      print(normalized_nonempty(["  Python  ", "", "  Data  "]))

walrus 运算符不应该滥用。它适合减少重复计算，但如果让表达式变难读，就违背了 Python 哲学。
