    description: 每次字符串清洗都要接住返回的新字符串。
    code: |
      raw = "  Python,Data,AI  "
      parts = raw.strip().lower().split(",")

      print(parts)
  - title: production
    description: 工程版把文本清洗写成函数，并处理空输入和重复分隔符。
    code: |
      def parse_tags(raw: str) -> list[str]:
          tags: list[str] = []

          for part in raw.split(","):
              tag = part.strip().lower()
              if tag:
                  tags.append(tag)

          if not tags:
              raise ValueError("at least one tag is required")

          return tags

      print(parse_tags("  Python,Data,,AI  "))
