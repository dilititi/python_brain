codeExamples:
  - title: 最小模型
    description: 装饰器接收函数，返回一个新的函数。
    code: |
      def loud(func):
          def wrapper():
              result = func()
              return result.upper()
          return wrapper

      @loud
      def greet():
          return "hello"

      print(greet())
  - title: 保留元信息
    description: functools.wraps 让包装后的函数保留原来的名字和文档。
    code: |
      from functools import wraps

      def trace(func):
          @wraps(func)
          def wrapper(*args, **kwargs):
              print("calling", func.__name__)
              return func(*args, **kwargs)
          return wrapper

      @trace
      def add(a, b):
          return a + b

      print(add(2, 3))
---

装饰器不是“神奇的 @ 符号”，而是函数式组合。`@decorator` 等价于 `func = decorator(func)`，这句话就是最小心智模型。
