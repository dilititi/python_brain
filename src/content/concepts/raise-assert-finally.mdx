---
title: raise、assert 与 finally
summary: raise、assert 和 finally 分别负责抛错、检查假设和保证收尾。
whyImportant: 真实程序必须面对失败路径。主动抛错能暴露不合法状态，assert 能守住开发期不变量，finally 能确保文件、锁或连接被清理。
definition: raise 用来抛出异常，assert 用来检查调试期假设，finally 用来无论是否异常都执行清理。
mentalModel: raise 是报警，assert 是开发期断言，finally 是离开现场前必须做的收尾。

codeExamples:
  - title: naive
    description: 用默认值掩盖非法输入，会让调用者以为业务真的成功了。
    code: |
      def invoice_total(quantity):
          if quantity <= 0:
              return 0
          return quantity * 20

      print(invoice_total(-2))
  - title: standard
    description: raise 明确拒绝非法状态，assert 守住开发期不变量。
    code: |
      def invoice_total(quantity: int) -> int:
          if quantity <= 0:
              raise ValueError("quantity must be positive")
          assert quantity < 1000, "bulk orders need a separate flow"
          return quantity * 20

      print(invoice_total(3))
  - title: production
    description: 工程版用 finally 保证收尾动作发生，即使中途抛错也不会跳过清理。
    code: |
      def invoice_total(quantity: int) -> tuple[int, list[str]]:
          audit_log: list[str] = []
          audit_log.append("open")

          try:
              if quantity <= 0:
                  raise ValueError("quantity must be positive")
              assert quantity < 1000, "bulk orders need a separate flow"
              total = quantity * 20
          finally:
              audit_log.append("close")

          return total, audit_log

      print(invoice_total(3))
---
`try-except` 是处理错误，`raise` 是制造清楚的错误，`finally` 是清理现场。它们合在一起，才是完整的异常控制流。
