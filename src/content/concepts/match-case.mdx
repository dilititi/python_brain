title: match-case
summary: match-case 用模式匹配根据数据形状和取值选择分支。
whyImportant: 解析命令、处理嵌套字典、区分事件类型时，普通 if 链会很散。match-case 能把“数据长什么样”直接写进分支条件。
definition: match-case 是 Python 的结构化模式匹配语法，根据对象形状和取值选择分支。
mentalModel: match-case 像把数据拿去对一组模板，匹配到哪个模板就执行哪个分支。

codeExamples:
  - title: naive
    description: 用 if 链解析结构化数据时，取字段和判断形状会散在每个分支里。
    code: |
      event = {"type": "open", "path": "README.md"}

      if event.get("type") == "open":
          print(f"open {event.get('path')}")
      elif event.get("type") == "save":
          print(f"save {event.get('path')}")
      else:
          print("unknown event")
  - title: standard
    description: match-case 直接匹配数据形状，让分支围绕结构展开。
    code: |
      event = {"type": "open", "path": "README.md"}

      match event:
          case {"type": "open", "path": path}:
              print(f"open {path}")
          case {"type": "save", "path": path}:
              print(f"save {path}")
          case _:
              print("unknown event")
  - title: production
    description: 工程版加入类型守卫和错误分支，让不合格事件尽早暴露。
    code: |
      from typing import Any

      def dispatch(event: dict[str, Any]) -> str:
          match event:
              case {"type": "open", "path": str(path)} if path:
                  return f"open {path}"
              case {"type": "save", "path": str(path)} if path:
                  return f"save {path}"
              case {"type": unknown}:
                  raise ValueError(f"unsupported event type: {unknown}")
              case _:
                  raise ValueError("malformed event")

      for event in [
          {"type": "open", "path": "README.md"},
          {"type": "save", "path": "report.csv"},
      ]:
          print(dispatch(event))
---
match-case 不是 switch 的简单替代。它更强的地方在于“匹配结构”，比如元组、字典、类实例和嵌套数据。
