---
title: 闭包
summary: 闭包让内层函数记住创建它时外层作用域里的变量。
whyImportant: 装饰器、回调、工厂函数和轻量状态封装都依赖闭包。理解它能解释为什么函数返回后，内部函数仍然能使用当时保存的配置。
definition: 闭包是函数和其引用的外部变量环境组合在一起的结果。
mentalModel: 闭包像函数随身带了一只小背包，里面装着创建它时需要的上下文。

codeExamples:
  - title: naive
    description: 用全局变量保存配置时，后一次修改会影响所有调用点。
    code: |
      discount_rate = 0.9

      def apply_discount(price):
          return price * discount_rate

      vip_discount = apply_discount
      discount_rate = 0.5

      print(vip_discount(100))
  - title: standard
    description: 闭包让返回的函数记住创建它时的配置。
    code: |
      def make_discount(rate):
          def apply(price):
              return price * rate
          return apply

      vip_discount = make_discount(0.9)
      student_discount = make_discount(0.5)

      print(vip_discount(100))
      print(student_discount(100))
  - title: production
    description: 工程版把闭包配置和调用参数都校验清楚，再返回可复用函数。
    code: |
      from collections.abc import Callable

      def make_discount(rate: float) -> Callable[[float], float]:
          if rate <= 0 or rate > 1:
              raise ValueError("rate must be between 0 and 1")

          def apply(price: float) -> float:
              if price < 0:
                  raise ValueError("price cannot be negative")
              return round(price * rate, 2)

          return apply

      vip_discount = make_discount(0.9)
      print(vip_discount(100))
