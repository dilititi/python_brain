codeExamples:
  - title: naive
    description: 没有共享父类时，相似对象会重复实现同一套状态和方法。
    code: |
      class EmailNotifier:
          def __init__(self, target):
              self.target = target

          def send(self, message):
              return f"email to {self.target}: {message}"

      class SmsNotifier:
          def __init__(self, target):
              self.target = target

          def send(self, message):
              return f"sms to {self.target}: {message}"

      print(EmailNotifier("ada@example.com").send("ready"))
  - title: standard
    description: 子类复用父类初始化逻辑，并覆盖差异化行为。
    code: |
      class Notifier:
          def __init__(self, target):
              self.target = target

          def send(self, message):
              return f"message to {self.target}: {message}"

      class EmailNotifier(Notifier):
          def send(self, message):
              return f"email to {self.target}: {message}"

      print(EmailNotifier("ada@example.com").send("ready"))
  - title: production
    description: 工程版用抽象基类明确子类必须实现的协议，并校验共享输入。
    code: |
      from abc import ABC, abstractmethod

      class Notifier(ABC):
          def __init__(self, target: str):
              if not target:
                  raise ValueError("target is required")
              self.target = target

          @abstractmethod
          def send(self, message: str) -> str:
              raise NotImplementedError

      class EmailNotifier(Notifier):
          def send(self, message: str) -> str:
              if not message:
                  raise ValueError("message is required")
              return f"email to {self.target}: {message}"

      print(EmailNotifier("ada@example.com").send("ready"))

继承很强，但也容易让层级变复杂。新人阶段先理解“复用和覆盖”，等项目真的需要抽象层次时再深入多继承和 MRO。
