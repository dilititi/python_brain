title: 推导式
summary: 推导式用紧凑语法从可迭代对象生成列表、字典或集合。
whyImportant: 数据过滤、字段转换、批量清洗常常是一进一出的容器构造。推导式能把这种意图压成清晰表达，但也要知道何时改回普通循环。
definition: 推导式是从可迭代对象生成列表、字典或集合的紧凑语法。
mentalModel: 推导式像把 for 循环压成一条数据管道，左边是产出，右边是来源和条件。

codeExamples:
  - title: naive
    description: 普通循环可以完成清洗去重，但一进一出的转换意图被拆散了。
    code: |
      tags = [" Python ", "", "data", "PYTHON"]
      cleaned = []

      for tag in tags:
          text = tag.strip().lower()
          if text and text not in cleaned:
              cleaned.append(text)

      print(cleaned)
  - title: standard
    description: 推导式把“清洗、过滤、构造容器”的意图集中到一行。
    code: |
      tags = [" Python ", "", "data", "PYTHON"]

      cleaned = sorted({tag.strip().lower() for tag in tags if tag.strip()})

      print(cleaned)
  - title: production
    description: 工程版保留推导式表达核心转换，同时把边界条件放进函数入口。
    code: |
      from typing import Iterable

      def normalize_tags(tags: Iterable[str], min_length: int = 1) -> list[str]:
          if min_length < 1:
              raise ValueError("min_length must be positive")

          normalized = [tag.strip().lower() for tag in tags]
          unique_tags = {tag for tag in normalized if len(tag) >= min_length}
          return sorted(unique_tags)

      print(normalize_tags([" Python ", "", "data", "PYTHON"], min_length=2))
---
推导式不是越短越好。它适合表达简单的数据变换；一旦条件和嵌套过多，普通循环反而更清楚。
