codeExamples:
  - title: naive
    description: 用字符串拼路径时，少一个分隔符就会拼出错误路径。
    code: |
      folder = "reports"
      filename = "summary.csv"

      path = folder + filename
      print(path)
  - title: standard
    description: Path 对象用 / 拼接路径，文件名、后缀和父目录都有清楚的方法。
    code: |
      from pathlib import PurePosixPath

      path = PurePosixPath("reports") / "2026" / "summary.csv"

      print(path.name)
      print(path.suffix)
      print(path.parent)
  - title: production
    description: 工程版把路径构造写成函数，并拒绝空文件名、路径穿越和错误后缀。
    code: |
      from pathlib import PurePosixPath

      def report_path(folder: str, filename: str) -> PurePosixPath:
          if not filename:
              raise ValueError("filename is required")

          candidate = PurePosixPath(filename)
          if candidate.name != filename:
              raise ValueError("filename must not contain directories")
          if candidate.suffix != ".csv":
              raise ValueError("report file must be .csv")

          return PurePosixPath(folder) / candidate

      print(report_path("reports/2026", "summary.csv"))
