summary: 模块把代码放进独立文件或包中，通过 import 在项目内复用。
whyImportant: 当一个脚本拆成多个文件时，模块就是最基本的组织单位。理解模块命名空间，才能搭建清晰项目结构并避免到处复制函数。
definition: 模块是一个 Python 文件或包中的命名空间，可以被其他代码导入。
mentalModel: 模块像工具抽屉。常用工具收进文件，需要时用 import 拿出来。

codeExamples:
  - title: naive
    description: 所有逻辑堆在一个脚本里时，复用只能靠复制粘贴。
    code: |
      radius = 3
      area = 3.14 * radius * radius
      print(round(area, 2))

      other_radius = 5
      other_area = 3.14 * other_radius * other_radius
      print(round(other_area, 2))
  - title: standard
    description: 模块把可复用函数放进独立文件，再通过 import 使用。
    runnable: false
    code: |
      # geometry.py
      import math

      def circle_area(radius):
          return math.pi * radius * radius

      # report.py
      from geometry import circle_area

      print(round(circle_area(3), 2))
  - title: production
    description: 工程版让模块只暴露稳定函数，并用 main 入口隔离脚本运行逻辑。
    runnable: false
    code: |
      # geometry.py
      import math

      def circle_area(radius: float) -> float:
          if radius < 0:
              raise ValueError("radius cannot be negative")
          return math.pi * radius * radius

      if __name__ == "__main__":
          print(round(circle_area(3), 2))
