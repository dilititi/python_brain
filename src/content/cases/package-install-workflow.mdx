scenario: Web 或数据项目需要安装 requests、flask、pandas 等第三方库，但不能污染系统 Python。

codeVersions:
  - label: standard
    code: |
      # 在终端执行：
      # python -m venv .venv
      # .venv\Scripts\python -m pip install requests
      # .venv\Scripts\python -m pip freeze > requirements.txt
      print("project dependencies are isolated")
pitfalls:
  - 在全局环境安装依赖会污染其他项目，也让部署环境难以复现。
extensions:
  - 生成 requirements 或 pyproject 依赖清单，并记录安装、升级和卸载流程。

这个案例把“装包”从零散命令变成工程流程。新人越早理解环境隔离，后面遇到依赖冲突时越少崩溃。
