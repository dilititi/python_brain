      from pathlib import Path

      def preview_renames(folder):
          for index, file in enumerate(Path(folder).glob("*.txt"), start=1):
              new_name = file.with_name(f"report-{index:03d}{file.suffix}")
              print(file.name, "->", new_name.name)

      preview_renames(".")

`pathlib` 的关键优势是让路径操作从字符串拼接变成对象方法。先预览，再真正 `rename`，也是自动化脚本的好习惯。
