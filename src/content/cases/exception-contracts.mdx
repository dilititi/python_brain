      def parse_positive(raw):
          try:
              value = int(raw)
              if value <= 0:
                  raise ValueError("value must be positive")
              return value
          finally:
              print("parse finished")

      print(parse_positive("3"))

异常契约的重点是“失败也要有设计”。该拒绝时主动 `raise`，该收尾时放进 `finally`。
