      import json
      from pathlib import Path

      def load_config(path):
          try:
              return json.loads(Path(path).read_text(encoding="utf-8"))
          except FileNotFoundError:
              return {"city": "Hangzhou"}
          except json.JSONDecodeError:
              return {"city": "Hangzhou"}

      print(load_config("settings.json"))
pitfalls:
  - 假设配置文件一定存在且字段完整，会让缺文件、坏 JSON 和缺 key 混成同一种崩溃。
extensions:
  - 加入默认配置、字段校验和清晰错误提示，让配置加载成为稳定入口。

配置读取是 `pathlib`、`json` 和 `try-except` 的交叉点。这个案例也提醒新人：失败路径是程序设计的一部分。
