      def validate_user(data):
          errors = {}

          if not data.get("name"):
              errors["name"] = "name is required"

          if "@" not in data.get("email", ""):
              errors["email"] = "email is invalid"

          return errors

      print(validate_user({"name": "Ada", "email": "ada@example.com"}))
pitfalls:
  - 在检查空字符串之前直接 int() 转换，会让用户输入错误变成未处理异常。
extensions:
  - 把校验规则抽成函数，并返回统一的错误消息或字段级错误对象。

这个案例把 `if` 从抽象判断带回真实业务：判断不是为了练语法，而是为了保护后续代码不接收脏数据。
