codeVersions:
  - label: standard
    code: |
      records = [("Ada", "python"), ("Guido", "python"), ("Wes", "data")]
      seen_tags = {tag for _, tag in records}
      required = {"python", "data", "web"}

      for index in range(1, 6):
          if index == 3:
              continue
          print(index)

      print("missing:", required - seen_tags)
pitfalls:
  - 用 list 做大量成员判断会退化成反复线性扫描，数据量上来后报表会从秒级变成分钟级，用户通常只看到“系统越来越慢”而不知道瓶颈在成员测试。
extensions:
  - 把输入转换成 set 后生成差异报告，并导出缺失项与重复项。

这个案例让 tuple、set、range 不再是孤立类型，而是进入“记录、去重、序号、跳过”的真实数据处理动作。
