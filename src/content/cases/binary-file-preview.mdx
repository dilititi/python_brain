  data = "Python".encode("utf-8")

  for index in range(min(4, len(data))):
      print(index, data[index])

  print(data.decode("utf-8"))

二进制预览是理解 str 和 bytes 边界的好入口。文件、网络、图片和压缩包都会把这个边界推到你面前。
