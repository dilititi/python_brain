scenario: 新人安装 Python 后，先确认自己运行的版本、系统平台和语言哲学，避免一开始就混淆 Python 2、Python 3 或不同解释器环境。

code: |
  import platform
  import sys

  print(platform.python_version())
  print(platform.system())
  print(sys.executable)
---

这个案例不追求复杂，而是把“我到底在运行哪个 Python”变成第一个可观察事实。很多环境问题都从这里开始排查。
