code: |
  def handle(command: tuple[str, str | None]) -> str:
      match command:
          case ("hello", name) if name:
              return f"Hello, {name}"
          case ("version", _):
              return "Python 3"
          case _:
              return "Unknown command"

  print(handle(("hello", "Ada")))

现代语法不是为了追新。它应该让意图更清楚：f-string 让输出模板更清楚，类型注解让接口更清楚，match-case 让结构化分支更清楚。
